# 새벽 한 시 캐릭터 작업

- 새벽 한 시 MCP 도구로 사용자가 소유한 캐릭터와 설정만 조회하거나 수정합니다.
- 채팅 대화는 이 도구에서 하지 않습니다. 사용자가 대화 자체를 원하면 새벽 한 시 앱에서 진행하도록 안내합니다.
- 삭제, 공개 범위 변경처럼 결과가 큰 작업은 사용자의 요청이 명확할 때만 실행합니다.
- 이미지 생성은 앱의 계정별 사용 한도를 고려하고, 생성 요청이 있을 때만 시작합니다.
